# Docs

How content is produced is in the root `README.md`. These docs cover the app:

- `gestalts.md`: the model behind practice: gestalts, exercises, cards, goals.
- `videos.md`: immersion and explanatory videos, platforms.
- `data.md`: Dexie tables and how content gets into them.
- `algorithm.md`: how the queue picks the next exercise, high level.
- `algorithm-details.md`: one queue step in detail, goals, tuning knobs.
- `exercise-types.md`: the exercise types and how to add one.
- `debugging.md`: logging and the exercise preview.
- `credits.md`: attribution of third-party content.
